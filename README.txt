รายการเปลี่ยนแปลง
1. เปลี่ยน URL ระบบสารบรรณเป็น https://sarabun.bankhum.ac.th/
2. ปรับการ์ดและปุ่มเปิดระบบให้มีลักษณะเหมือนแอป ทั้งมือถือและคอมพิวเตอร์
   ใช้ไอคอนตามประเภทระบบครบทั้ง 15 การ์ด และเปลี่ยนไอคอนสารบรรณเป็นเอกสาร
3. จัดเมนูออมทรัพย์ที่มีอยู่แล้วไว้ลำดับที่ 4 พร้อมไอคอนกระปุกออมสิน
   ให้เห็นทันทีบนจอมือถือ โดยยังเลื่อนเมนูไปยังรายการอื่นได้
4. เมื่อกดออมทรัพย์ขณะการ์ดถูกซ่อนด้วยการค้นหาหรือกรอง จะล้างตัวกรองก่อนเลื่อนไปยังการ์ด
5. ปรับข้อความปุ่มสำหรับจอแคบ และรักษาการซ่อนผลลัพธ์ของระบบค้นหา/กรอง
